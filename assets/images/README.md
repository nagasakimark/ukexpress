# Pictures for UK Express

Every picture is a `.png` (any size; it is cropped to fit, 4:3 works best, about 800x600 or bigger). Replace a placeholder by saving your picture with **exactly the same file name** in the same folder. If a file is missing the game shows a coloured card instead, so nothing breaks.

File names are the English name in lower case with no spaces, apostrophes or punctuation, for example `kingscross.png`, `alanturing.png`, `summersolstice.png`.

Run `python tools/make_placeholders.py` after adding a station, hero or event to make its placeholder (existing files are never overwritten).

Extra photos: save up to 6 more pictures beside the base file as `<name>2.png` … `<name>7.png` (for example `birmingham2.png`). The game browses them with ◀ ▶ buttons and shows one of them first, at random.
